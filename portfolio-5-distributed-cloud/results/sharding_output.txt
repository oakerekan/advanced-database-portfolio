
==================== 1. Start 4 servers ====================
coordinator running on port 5440
shard_ikj running on port 5441
shard_lki running on port 5442
shard_yab running on port 5443

==================== 2. Each shard stores ONLY its own branch (enforced by a CHECK constraint) ====================
shard_ikj: table encounter_record created, CHECK (branch_id = 1)
shard_lki: table encounter_record created, CHECK (branch_id = 2)
shard_yab: table encounter_record created, CHECK (branch_id = 3)

==================== 3. Coordinator: partitioned table whose partitions live on the shards ====================
Partition key: LIST (branch_id)
Partitions: encounter_ikj FOR VALUES IN ('1'), FOREIGN,
            encounter_lki FOR VALUES IN ('2'), FOREIGN,
            encounter_yab FOR VALUES IN ('3'), FOREIGN
